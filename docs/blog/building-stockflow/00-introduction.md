Building StockFlow #01 — Por que estou construindo um sistema de gestão de estoque do zero?

Introdução

Todo desenvolvedor chega em um momento da carreira em que percebe que apenas concluir cursos e reproduzir tutoriais já não é suficiente. O próximo passo é enfrentar problemas reais, tomar decisões técnicas e construir software que evolui ao longo do tempo.

Foi exatamente com esse objetivo que nasceu o StockFlow.

Mais do que um projeto para praticar Laravel, o StockFlow será um sistema de gestão de estoque desenvolvido de forma incremental, sprint após sprint, seguindo práticas utilizadas em equipes de desenvolvimento profissionais.

Esta série documentará não apenas o código, mas também o processo de engenharia por trás de cada decisão.

---

O que é o StockFlow?

O StockFlow é um sistema de gestão de estoque que está sendo desenvolvido do zero.

O projeto foi pensado para simular um ambiente real de desenvolvimento, onde cada funcionalidade é planejada, implementada, testada, documentada e versionada antes da próxima etapa começar.

O objetivo não é construir um CRUD rapidamente.

O objetivo é construir um software que possa evoluir de forma sustentável.

---

Por que construir esse projeto?

Existem milhares de tutoriais ensinando Laravel.

A maioria mostra como criar um CRUD em poucos minutos.

Na prática, porém, um sistema não é apenas um conjunto de telas e endpoints.

Existem decisões de arquitetura, organização do domínio, testes automatizados, controle de versão, documentação, planejamento e manutenção contínua.

Foi justamente esse processo que decidi documentar.

Quero mostrar como um projeto cresce desde sua primeira linha de código até se tornar uma aplicação cada vez mais completa.

---

Como esta série será organizada?

Cada sprint representará uma etapa da evolução do StockFlow.

Ao final de cada sprint serão produzidos:

- Planejamento da Sprint.
- Implementação das funcionalidades.
- Artigos técnicos sobre as principais decisões.
- Testes automatizados.
- Pull Request.
- Release.
- Retrospectiva.

Assim, cada entrega ficará registrada tanto no código quanto na documentação e nos artigos da série.

---

O que esperar dos próximos artigos?

Nos próximos capítulos acompanharemos a construção completa do sistema.

Entre os assuntos que serão abordados estão:

- Modelagem de domínio.
- Laravel na prática.
- Arquitetura de software.
- Organização de código.
- Testes automatizados.
- Git e fluxo de desenvolvimento.
- Versionamento.
- Documentação técnica.
- Evolução contínua do projeto.

Cada artigo será baseado em decisões reais tomadas durante o desenvolvimento do StockFlow.

---

Conclusão

Este não será apenas um projeto de estudo.

Será um registro contínuo da construção de um software, documentando as decisões, os desafios e os aprendizados encontrados ao longo do caminho.

Se você gosta de acompanhar projetos desenvolvidos passo a passo, entendendo não apenas o que foi feito, mas principalmente por que cada decisão foi tomada, seja bem-vindo à série Building StockFlow.
