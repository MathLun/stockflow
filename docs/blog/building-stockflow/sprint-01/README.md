# Sprint 01 — Product Catalog

A primeira sprint da série Building StockFlow foi dedicada à construção do módulo Product Catalog, estabelecendo a base do domínio da aplicação.»

## Objetivo da Sprint

O principal objetivo desta sprint foi implementar o primeiro módulo funcional do StockFlow: o gerenciamento de produtos.

Além da implementação do CRUD completo, esta sprint também teve como propósito definir um padrão de desenvolvimento que será seguido ao longo de todo o projeto, incluindo planejamento, documentação, testes automatizados, versionamento, Pull Requests e releases.

## Entregas

Ao final da Sprint 01 foram entregues:

- ✅ Product Model
- ✅ Products Migration
- ✅ Product CRUD
- ✅ Request Validation
- ✅ Feature Tests
- ✅ API REST
- ✅ Documentação técnica
- ✅ Pull Request
- ✅ Release "v0.1.0"
- ✅ Sprint Retrospective
